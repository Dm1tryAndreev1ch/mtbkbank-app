# MT-Банк × CardDrop — Pitch Deck

## 1. Концепция продукта

**MT-Банк CardDrop** — банковский пакет для молодёжи до 25 лет, в котором каждая покупка превращается в игру. При оплате картой пользователь получает случайную коллекционную карточку (дроп), которая даёт кешбэк. Карточки объединяются в колоды, торгуются с друзьями и имеют «здоровье» — без активных трат карта постепенно умирает. Это мотивирует пользователя регулярно пользоваться картой, вовлекает его в соревновательную механику и создаёт вирусный эффект через обмен и торговлю.

Продукт состоит из двух неразрывно связанных частей, которые могут работать и независимо:
- **Банковский пакет «CardDrop»** — карта, переводы, аналитика, подписки
- **Игра CardDrop** — коллекционные карточки, колоды, квесты, торговля
